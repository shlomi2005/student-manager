# student-manager 

מערכת ניהול תלמידים פשוטה בשורת הפקודה, כתובה בפייתון.

## תיאור

התוכנית שומרת נתוני תלמידים (שם, ציון, כיתה) בקובץ CSV, ומאפשרת לנהל אותם דרך תפריט אינטראקטיבי: הצגת כל התלמידים, הוספת תלמיד חדש, חיפוש לפי שם, חישוב ממוצע כיתה, ואיתור התלמיד המצטיין.

## קובץ הנתונים

`students.csv` — קובץ ה-CSV שבו נשמרים הנתונים, עם שורת כותרת:

```
name,grade,class
```

## פונקציות עיקריות

- `load_students(filename)` — טוענת את רשימת התלמידים מהקובץ. אם הקובץ לא קיים, מחזירה רשימה ריקה.
- `save_students(filename, students)` — שומרת את רשימת התלמידים בחזרה לקובץ.
- `add_student(students, name, grade, class_name)` — מוסיפה תלמיד חדש לרשימה.
- `find_student(students, name)` — מחפשת תלמיד לפי שם, ומחזירה את הפרטים שלו או `None` אם לא נמצא.
- `class_average(students, class_name)` — מחשבת את ממוצע הציונים בכיתה מסוימת.
- `top_student(students)` — מחזירה את שם התלמיד בעל הציון הגבוה ביותר.
- `print_all(students)` — מדפיסה את כל התלמידים.

## הרצה

```bash
python manager.py
```

לאחר ההרצה יופיע תפריט עם האפשרויות הבאות:

```
1. הצג הכל
2. הוסף
3. חפש
4. ממוצע כיתה
5. מצטיין
6. שמור וצא
```
